# SQL Analysis

This folder contains the SQL queries used for data quality assessment, data cleaning and analysis for the Faith Specialist Hospital healthcare analytics capstone project.

## SQL Workflow

The files are numbered to show the order of the analysis:

1. **01_create_tables.sql** — creates the tables used for the project.
2. **02_data_quality_assessment.sql** — checks the data for missing values, duplicates and inconsistencies.
3. **03_data_cleaning.sql** — cleans and standardises the data for analysis.
4. **04_patient_demographics_analysis.sql** — examines patient demographics in relation to hospital outcomes.
5. **05_dama_analysis.sql** — analyses DAMA cases and the recorded reasons for DAMA.
6. **06_chronic_disease_analysis.sql** — examines the prevalence of chronic diseases and their relationship with hospital outcomes.
7. **07_lifestyle_factors_analysis.sql** — examines recorded lifestyle factors in relation to hospital outcomes.
8. **08_doctor_workload_analysis.sql** — examines admission workload and outcomes across doctors and medical specialties.
